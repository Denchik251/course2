# Рубежный контроль №1 — вариант 8

**Дисциплина:** Программирование и конструирование языков программирования (ПиК ЯП).  
**Предметная область:** Жёсткий диск — Компьютер.  
**Язык:** Python 3.9+ (без сторонних библиотек).  
**Репозиторий:** https://github.com/Denchik251/course2

## Что реализовано

Три класса: `HardDrive` (ID, название, объём в ГБ, ID компьютера), `Computer` (ID, название), `HardDriveComputer` (связь многие-ко-многим). Данные связываются по числовым идентификаторам. Тестовая выборка: 5 дисков, 4 компьютера, 10 связей многие-ко-многим.

В условиях отдельно задаются **номер предметной области** и **буква варианта запросов** (А, Б, В, Г, Д, Е). По номеру 8 устанавливается только предметная область, поэтому реализованы **все шесть буквенных вариантов**. По умолчанию запускается **А**. Уточните у преподавателя требуемую букву, если она назначается отдельно.

Для текстовых фильтров выполнена адаптация формулировок: фамилия сотрудника → имя диска, название отдела → название компьютера, слово «отдел» → «компьютер», зарплата → объём в ГБ. Имена «Атласов» и «Барсов» намеренно подобраны для проверки условия «оканчивается на ов».

## Запуск

```bash
python main.py
python main.py --variant Б
python main.py --variant В
python main.py --variant Г
python main.py --variant Д
python main.py --variant Е
```

На Windows, если `python` не найден, попробуйте `py main.py`.

## Проверка тестов

```bash
python -m unittest discover -s tests -v
```

## Состав проекта

- `main.py` — классы, тестовые данные, запросы 1–3 для А–Е.
- `tests/test_main.py` — автоматические проверки.
- `results_A.txt` — сохранённый пример выполнения варианта А.
- `report.pdf` — отчёт с текстом программы и результатами запуска (требуется методичкой).
- `.gitignore` — игнорирование временных файлов Python.

## Публикация в вашем репозитории GitHub

**Адрес репозитория:** https://github.com/Denchik251/course2

Если репозиторий уже содержит файлы, безопаснее сначала клонировать его, затем скопировать в полученную папку файлы этого проекта из ZIP (не удаляя существующие файлы):

```bash
git clone https://github.com/Denchik251/course2.git
cd course2
# Скопируйте сюда main.py, README.md, report.pdf, results_A.txt,
# .gitignore и папку tests из распакованного архива.

git commit -m "Добавлен рубежный контроль 1, вариант 8"
git push origin HEAD
```

Если репозиторий пустой и вы уже находитесь в папке распакованного проекта, можно выполнить:

```bash
git init
git add .
git commit -m "Рубежный контроль 1, вариант 8"
git branch -M main
git remote add origin https://github.com/Denchik251/course2.git
git push -u origin main
```

При публикации GitHub может запросить авторизацию. Команды изменяют репозиторий только после их выполнения на вашем компьютере.
