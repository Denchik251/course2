# Рубежный контроль №1 — вариант 8

**Дисциплина:** Программирование и конструирование языков программирования (ПиК ЯП)  
**Предметная область:** Жёсткий диск — Компьютер  
**Язык программирования:** Python 3.9+

## Описание

Программа моделирует связи **один-ко-многим** и **многие-ко-многим** между жёсткими дисками и компьютерами. Для хранения данных используются три класса:

- `HardDrive` — идентификатор, название, объём в ГБ, идентификатор компьютера;
- `Computer` — идентификатор и название компьютера;
- `HardDriveComputer` — идентификаторы связанных диска и компьютера.

В программе представлены тестовые данные: 5 жёстких дисков, 4 компьютера и 10 записей связи многие-ко-многим. Связывание записей выполняется по идентификаторам.

Реализованы три запроса для каждого буквенного варианта (А, Б, В, Г, Д, Е): сортировка, вычисление агрегатных характеристик и выборка по текстовым условиям. Количественный показатель — объём диска в ГБ. Для текстовых условий используются названия дисков и компьютеров.

## Запуск

```bash
python main.py
```

По умолчанию выполняется вариант А. Для запуска другого набора запросов:

```bash
python main.py --variant Б
```

Допустимые значения параметра `--variant`: `А`, `Б`, `В`, `Г`, `Д`, `Е`.

## Тестирование

```bash
python -m unittest discover -s tests -v
```
